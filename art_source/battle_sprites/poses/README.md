# Battle poses: stand / attack / hit

Three single-frame sprites per loadout. The game swaps between them (no tweening):
`sprites/<class>_<sex>_<loadout>_<stand|attack|hit>.png` (399x270, transparent; the body sits at x=133, y=70 like the stand sprites).

- **stand** = the existing grip body (`../grip_bodies`).
- **attack / hit** = Canva edits of each grip body (one per stance: 1h, 2h, reach, bow), redrawn in a strike pose and a flinch pose
  with the same flat magenta guide rods in the fists. Canva media ids: `ids_1.json`, `ids_2.json`.
- Weapons are never generated by Canva; they are drawn in code (`../animation/anim.py` weapon set) at each pose's measured grip.

## Pipeline
1. `process_pose.py` - reads the rods (same rules as `grip_bodies/process2.py`), inpaints the rod pixels, writes
   `bodies/`, `grips/grips_<name>.json` and skin layers in `layers/` (tinted at runtime with the portrait skin ramps).
   - A rod only gives an axis: attack poses point the weapon forward, hit poses point it up.
   - 1h attack: the front hand is the lower (thrusting) fist, the back hand the raised one.
   - 2h attack rods that only stick out in front: the fists sit at the end nearer the body.
   - Rod mask is grown only from pure #FF00FF pixels, so the Mage's violet robe is not taken for a rod.
2. `compose.py` - tints, aligns the feet to the stand sprite, draws weapons and fists, writes `sprites/` and `review.png`.
   - Reach attacks are scaled x1.25 (Canva drew the deep spear lunge smaller; see `headscale.py`).
   - Mage hit: the staff is drawn behind the body so the orb does not cover the face.
